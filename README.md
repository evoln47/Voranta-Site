# voranta-site

Marketing site for voranta.co. Single-page static HTML using the locked Voranta design system (Fraunces + Geist + Geist Mono, cyan accent on cool cream).

## Deploy

Auto-deploys via Vercel on every push to `main`.

## Edit workflow

1. Edit `index.html` locally or via GitHub web editor
2. Commit to `main`
3. Vercel deploys in ~30 seconds

## Assets

- `voranta-wordmark.svg` — locked wordmark, embedded inline in `index.html`
- `voranta-favicon.svg` — primary favicon (cyan asterisk on paper)
- `voranta-favicon-*.png` — PNG fallbacks for browsers without SVG favicon support
